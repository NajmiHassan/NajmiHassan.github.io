**Tools and Technologies:** scikit-learn, XGBoost, SMOTE, SHAP

- Built a symptom-based multi-class classifier for mental disorder using Random Forest and XGBoost
- Applied SMOTE to handle class imbalance in clinical data and SHAP for model interpretability
- Achieved evaluation 95.8% on RF and 95.9% on XGBoost via 5-fold cross-validation and confusion matrix analysis
